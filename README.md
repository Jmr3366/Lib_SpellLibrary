# Lib_SpellTemplate
![alt text](https://github.com/Jmr3366/Lib_SpellLibrary/blob/main/LibSpellTemplate.webp?raw=true)
Lib_SpellTemplate is a token used with the Spell Library that provides a method to capture tokens that
are in a circle, cone, square, beam.
This token can use Lights and Sights and provides information back to the caster on who was hit and how much.
